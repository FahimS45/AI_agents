# 🤖 AI Agent Playground  

Welcome to **AI_agent** — a personal repository where I explore, experiment, and build with AI agents.  
This repo is a collection of projects that range from **single AI agents** to **multi-agent systems** and **AI-powered applications**.  

The goal of this repository is simple:  
- Learn by building.  
- Experiment with different AI models (LLMs, CV models, multimodal, etc.).

- Document the journey of developing **AI-native apps**.

## 🌱 Why AI Agents?  
AI agents represent the next step in leveraging AI models — they **perceive, reason, and act**.  
By chaining reasoning with actions (like querying APIs, interacting with environments, or collaborating with other agents),  
they unlock powerful automation and problem-solving capabilities.
